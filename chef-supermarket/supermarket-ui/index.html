🍴 Chef Supermarket (Demo Instance)

Internal cookbook repository for CI/CD demo environment

ℹ️ This is a lightweight demo substitute for Chef Supermarket. Community cookbooks (java, docker) resolve from supermarket.chef.io. The myapp cookbook is served from this instance.

myapp v1.0.0demo

Deploys the demo Spring Boot application. Downloads JAR from Nexus, writes systemd unit file, enables and starts the service.

GET /api/v1/universe

java v10.0.0

Installs Java runtime. Resolves from the public Chef Supermarket (supermarket.chef.io). Required by myapp cookbook.

docker v10.0.0

Installs and manages Docker Engine. Resolves from the public Chef Supermarket. Optional dependency for container-based deployments.

API Endpoints

Compatible with knife supermarket commands:

GET /api/v1/status GET /api/v1/universe GET /cookbooks/ (file listing)
